# Hints (use only if stuck ≥5 minutes)

1. If lengths differ, return `False` immediately.
2. Count characters in `s` (dict or `collections.Counter`), then subtract / compare with `t`.
3. Sorting both strings and comparing also works: `sorted(s) == sorted(t)`.
4. Prefer counting in interviews when you want to mention O(n) time / O(k) space (k = alphabet size).
