# Easy — Contains duplicate

**Pattern:** arrays + hash set  
**Timebox:** ~15–20 minutes

## Problem

Given a list of integers `nums`, return `True` if any value appears **at least twice**, otherwise `False`.

## Examples

```
nums = [1, 2, 3, 1]     → True
nums = [1, 2, 3, 4]     → False
nums = [1, 1, 1, 3, 3]  → True
```

## Constraints (interview-scale)

- `1 <= len(nums) <= 100_000`
- Values fit in a normal Python `int`

## Deliverable

Implement `contains_duplicate(nums: list[int]) -> bool` in `solution.py`.
